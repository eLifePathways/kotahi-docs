To reach these settings in Kotahi, choose **Settings → Configuration**.

Settings relevant to the Production page, controlling output when using the
‘Reference’ parser. For the tools these settings govern, see
[Check and improve citations](../../how-to/check-citations/).

## The four fields

| Field | What it does |
| --- | --- |
| **Email to use for citation search** | The contact address Kotahi sends with citation lookups. Use a shared address that someone monitors, not a personal one. |
| **Number of results to return from citation search** | How many candidate matches a lookup offers. Default 3. |
| **Select style formatting for citations** | The citation style applied to output — for example Chicago Manual of Style (CMOS). |
| **Select locale for citations** | The locale used when formatting citations — for example `en-US`. |
